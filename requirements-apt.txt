# Build/runtime system dependencies for OrbbecSDK_ROS2.
#
# Install with:
#   sed 's/#.*//' requirements-apt.txt | envsubst | xargs -r sudo apt install -y
#
# ${ROS_DISTRO} is expanded from the environment, so source your ROS setup first:
#   source /opt/ros/humble/setup.bash
#
# Alternatively, rosdep covers most of these from the package.xml files:
#   rosdep install --from-paths . --ignore-src -r -y
# but it will NOT pull the four entries marked [rosdep-gap] below, which
# CMakeLists.txt requires via find_package() without a matching <depend> tag.
